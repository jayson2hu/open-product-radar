# 来源权限与事实边界

运营台账应按行为分别记录：读取公开元数据、保留摘录、公开展示、衍生分析、商业使用、保留期限。当前数据库使用来源状态、统一权限状态和审核理由；逐操作授权仍依靠本台账人工核对，尚未实现通用权限矩阵。这里是接入基线，不替代实际授权记录；生产启用前由负责人记录条款链接、核查时间和适用范围。

| 来源 | 首版接入 | 行为边界 | 失效处理 |
|---|---|---|---|
| GitHub REST | 仓库公开元数据、版本、计数快照 | 固定官方 API；不抓私有仓库；不运行代码；遵守限额与响应退避 | 保留最后成功值；采集故障不能写零 |
| 官方网站/文档 | 编辑录入证据链接 | 不开放用户 URL 即时抓取；来源展示权限与采集权限分别核查 | 暂停展示、撤回关联内容并保留允许的审计 |
| Hacker News | 后续候选来源 | 当前不作为已实现来源宣传；接入前记录用途与条款 | 允许暂停，不影响历史资料 |
| 作者提交 | 纠错入口、审核队列 | 作者自述不自动成为平台事实；提交链接不自动访问 | 拒绝恶意或不适用提交 |
| Product Hunt/Reddit/外部趋势站 | 未启用 | 没有适用商业许可不作收费核心依赖 | 不绕过封禁、配额或访问控制 |

## 编辑核查

1. 确认实体与适用版本、套餐、部署方式。
2. 记录原始 URL、允许的最小摘录、采集时间及来源发布时间；无发布时间保留空。
3. 标注候选、待审核、已核查、冲突或过期。名称相似不能确认官方关系。
4. 检查引用是否真正支持描述；重要限定条件必须随事实显示。
5. 发布与更正记录操作者、原因及时间；撤回信息不进入后续摘要。

演示库始终标识为样例。来源 URL 真实存在不等于当前演示摘录、指标或结论已经实测。首次观测不能当作首次发布。站内样本排名不是 GitHub 官方 Trending。

## 删除与恢复

撤销来源或删除证据后应处理对应事实、关系、事件、摘要和投递；私有笔记不会自动转公开。恢复旧备份前必须重新应用删除记录。已发送的邮件无法召回，重大错误需要经授权发送更正。
