# 服务端检查与修复记录 · 2026-09-22

范围：HTTP API、会话与角色、来源和证据可见性、私有研究数据、编辑后台、比较矩阵、公开状态语义。只使用隔离的内存测试数据库；没有修改实采数据库，没有构建前端或重启服务。

## 已复现并修复的问题

| 优先级 | 可复现场景与原行为 | 修复结果 |
| --- | --- | --- |
| P1 | 事件或判断引用两条证据，其中一个来源被撤销；原接口删掉无效引用，但仍展示完整衍生内容 | 引用集必须全部有效，才允许展示事件、套餐、关系与结论；否则隐藏或降为未知。公开事件计数采用同一规则 |
| P1 | 从管理员 GitHub ID 白名单移除账号后，已存储的管理员角色和旧会话仍有管理权限 | 每次已登录请求按当前数字 ID 白名单校验管理员资格；既有普通账号加入白名单也会生效。独立的编辑角色保留 |
| P2 | 已遮蔽的来源介绍和标签仍能被 `q` 搜索命中 | 搜索和排序使用可公开的数据投影；撤销来源的正文、标签、语言、许可、指标与曲线停止展示，稳定对象身份仍可检索 |
| P2 | 编辑角色读取后台概览时能获得收款凭证、退款理由、用户行为分组和邮件队列标识 | 编辑仅获得内容审核所需数据；资金记录、用户行为聚合和投递队列限管理员。审核日志也按内容操作白名单筛选 |
| P2 | 已确认关系直接返回内部审核 `reason` | 公开关系不再返回内部审核理由；编辑后台仍可读取审核记录 |
| P2 | 同一维度存在两个不同版本或套餐的相反判断时，比较矩阵默认显示第一条判断 | 不再静默选择首条；结果标为待核对，并保留各判断的范围和证据 `variants` |

前四项及多范围比较问题先由新回归测试复现失败，再进行修复。另补充了以下边界修复：实体附加 JSON 无法覆盖稳定身份与审核字段；曲线保留最近 200 次观察而非最早 200 次；同一代理后的一个已登录账号无法耗尽其他账号的请求限额。

## 新增的公开接口说明

- `/session.capabilities.auth`：`github_enabled`、`demo_enabled`、`login_available`，不可用时提供 `unavailable_reason`。不返回客户端 ID、密钥、管理员名单或内部配置路径。生产环境不开放演示登录；GitHub 登录要求已配置凭据和有效 HTTPS 公开地址。
- `/session.capabilities.collection_scope`：说明当前为人工指定的公开仓库样本，没有自动全网发现，也不是实时榜单。
- `/feed.content_status`：对象数量、实际可公开事件数量、待审核事件数量及待审核版本数量。只提供计数，不返回待审核标题、摘要或证据原文。
- 实体详情 `content_status`：仅该对象的上述事件计数。详情 `collection` 只包含与该对象相关的来源。
- 列表 `sort`：返回 `requested`、`effective`、`period`、`comparable_count`。无可比较增量时明确实际按名称排列，不声称完成净增长排序。
- `/admin/overview.capabilities.business_admin`：表示是否允许查看商业与用户运营数据。

来源暂停与来源撤销继续区别处理：暂停采集可以保留既有合法记录；`blocked` 停止相应证据与衍生数据的展示。实际删除仍通过删除接口和删除台账传播。审核通过的证据也必须仍满足来源权限条件，才能用于新事实发布。

## 验证

执行：

```text
node --test --test-isolation=none tests/backend-review.test.mjs tests/api.test.mjs tests/collection-status.test.mjs
```

结果：30 项通过，其中本轮新增 10 项专属回归。原有同源与 CSRF 校验、账户之间的任务和备注隔离、摘要去重、退订、来源删除传播、生产与演示库隔离、编辑发布流程仍通过。

覆盖的反例包括：一个有效引用不能掩盖另一个被撤销的引用；已隐藏原文不能作为搜索探针；移除管理员授权后旧会话立即失去管理权限；公开接口不暴露关系审核理由和待审内容；登录能力响应不包含凭据；生产环境不因缺少 OAuth 配置而启用演示账户。

## 本轮未声称完成的验证

- 没有执行真实 GitHub OAuth 回调或外部邮件投递；只验证配置判断、状态校验和本地权限路径。
- 证据是否真正支持具体业务判断、复杂许可证结论及实测可靠性，仍需要人工内容核查；附有链接不等于已经自动证明事实。
- 不支持自动替用户选择版本或套餐。多范围比较现在明确显示不确定性，未新增版本选择器。
- 未将本地测试当成生产容量承诺。最新读取实现的合成性能基线由集成流程单独重跑；匿名访问在反向代理后的精确客户端限流仍应由可信网关配置负责，不信任用户随意提供的转发 IP 请求头。

Worker 的同类多证据发送校验、删除后原文缓存处理及任务租约修复由采集/投递检查同步落实，最终结果以整体验收和相应 Worker 回归测试为准。
