## 初查证据与影响

| 问题 | 代码证据 | 用户影响 | 处理方向 |
| --- | --- | --- | --- |
| 增长状态只写“历史不足” | `RepositoryTable`、`EntityDetail`、`Method` 使用简短术语 | 容易误认为采集失败，或以为过一天必然自动更新 | 统一解释总量、早期记录、再次采集与持续调度 |
| 没有可比增长仍显示净变化排序及序号 | `Discover` 的排序说明固定；`RepositoryTable` 渲染 `repo-rank` | 把按名称列出的项目误认成增长榜 | 使用 API 的实际排序口径，移除伪排名序号 |
| 产品/事件为空时缺少背景 | 产品面板和目录只有“暂无变化”等统一文案 | 已采集仓库与待审核版本的成果不可见 | 用公开内容库存计数区分仓库、产品档案、已发布事件与待审核版本 |
| 正式环境登录入口直接进入 OAuth | `Login` 的非演示分支无条件链接 `/auth/github` | 未配置登录时跳入 503 | 根据 `/session.capabilities.auth` 显示可用登录或公开浏览说明 |
| 模态窗口与手机侧栏焦点不完整 | 模态初始焦点在容器；侧栏没有键盘焦点约束 | 键盘可能离开弹层或难以关闭导航 | 初始焦点、Tab 闭环、Escape、返回焦点、导航展开状态 |
