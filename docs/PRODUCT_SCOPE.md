# 产品范围和数据说明

开源产品雷达帮助开发者围绕具体任务发现公开项目、比较有来源的能力和限制，并跟踪后续变化。

## 已支持的路径

1. 浏览已收录的公开仓库，按研究方向、语言和关键词筛选。
2. 查看项目资料、指标观察时间、经审核的事件与原始证据。
3. 登录后创建私有研究任务、比较候选、记录笔记和采用判断。
4. 保存关注原因，选择站内更新或已配置的订阅通知。
5. 编辑和管理员维护来源、审核内容、处理纠错和删除、核对任务及预算。

演示模式提供明确标识的合成样本；正式模式从独立空数据库启动。当前自动采集支持 GitHub 官方公开仓库和版本 API，版本及证据先进入待审核流程。产品官网、价格和能力资料需要人工维护。

## Star 总数与增长

总数是本次采集时 GitHub 返回的 Star 数。计算 24 小时增长还需要约 24 小时前的快照；计算 7 天增长还需要约 7 天前的快照。两次记录的来源和统计口径必须一致。

首次采集只有一个时间点，无法算增长。它不表示项目刚成立，也不表示采集失败。未启用后续采集时，等待一天或一周不会自动获得增长数据。缺少比较记录时不以零代替。

发现页覆盖的是已配置的有限样本；页面排序不是 GitHub 官方 Trending。Star 数不代表真实用户、收入或可靠性。

## 发布与部署边界

公开仓库存放源码、测试、配置样例及实施说明；本地数据库、备份、账户资料、凭据、生成产物和原始需求附件不属于源码交付。运行产物按操作手册在本地生成。

正式运营仍需要身份与来源配置、持续数据积累、内容审核、部署和恢复验证，以及真实使用反馈。现有功能和演示结果不等于商业验证已经完成。
