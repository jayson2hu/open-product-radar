`npm run test:e2e`：本机 Chrome 的 10 个实际浏览器场景。匿名发现、筛选、显式登录、任务/候选/证据/笔记/判断保存、跟踪管理、摘要、编辑与管理员入口、后台、产品证据事件录入发布，以及 390px 手机导航和逐项比较。测试使用独立内存数据库，不写日常工作区。截图已人工查看；页面无横向溢出，未发现浏览器运行错误和意外 API 错误。

`python scripts/verify-local-collection.py`：真实本地预览 12 项检查通过。核对已保存的 8 个仓库及 Star 总量、观察时间、待审版本、采集状态、缺少增长基线、登录说明、焦点、异常链接与 404 恢复，以及手机导航和溢出。只读现有资料，不重新访问 GitHub、不生成快照；浏览器埋点请求被拦截，避免把验收流量写成产品使用。

`npm run build`：前端正式构建通过。`npm run worker -- --once`：离线默认流程通过，不自动采集或向外部发送邮件。真实本地服务健康检查与备份命令也已执行成功。

依赖审计发现 Vite 6.3.5 的已知开发服务漏洞，已升级并锁定兼容修复版本 6.4.3。2026-09-22 npm 安全公告复查为 0 个已知依赖漏洞；这不等于代码没有任何安全风险。

## 真实 GitHub 连通检查

运行 `node scripts/check-github.mjs microsoft/playwright`，使用真实官方公开 API，成功取得稳定 ID `gh:221981891`、当前计数和 30 条待审核版本。第一次采集没有历史基准，delta_24h 为 null。采集结果记录于 `artifacts/github-live-check.json`，未导入演示或正式数据库，也未自动批准商业来源权限。

该检查证明单次公开 API 路径可用，不能证明长期配额、商业许可、全量覆盖或连续 24h / 7d 采样质量。真实 OAuth 往返和真实邮件收发需要实际账号配置后另测。

## 性能

`npm run benchmark` 使用本机 Windows / Node 24 / Ryzen 7 6800H、隔离内存 SQLite，1,012 个合成实体和 100,022 条快照，20 并发、100 个列表请求。初次 P95 为 1,258ms，移除列表 N+1 查询后降至 62ms；本轮加入全部引用校验、内容计数和排序说明后重新测得 P95 132ms、P50 105ms，满足内部 800ms 目标。最新结果见 `artifacts/benchmark.json`。

这不是正式 SLA，未包含磁盘、TLS、网络、并行写入、邮件、采集或 PostgreSQL。目标环境仍需压测和持久存储恢复演练。
